# Package repository

The package repository provides packages. A package consists of files or the paths to the files. The package repository is general and does not only work with a specific format. Thus, any application parts can be obtained with it. Examples are FunctionBlocks, Communications, Poolings, Validators, TypeConverter, ... The packages are ideally available for different operating systems. The service can be available on the Internet, in the local network or on the computer itself. For large locations/customers with special security requirements, the customer is responsible for the package repository.
